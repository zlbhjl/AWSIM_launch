# UターンODE/SDE 初期基準実験（2026-10-05）

## 実験設定

- ODEの代表3ケース（危険、境界近傍、安全）を `max_step_sec = 0.04, 0.02, 0.01, 0.005` 秒で実行した。
- 非零ノイズSDEは固定刻み Euler--Maruyama、零ノイズSDEは決定論的ODEと同じ
  `solve_ivp` 経路を用いた。
- SDE感度実験は各条件100 seed（1000--1099）、`sde_dt_sec = 0.01` 秒で実行した。
- dynamicsの時刻0はAWSIMのUターン開始イベントに合わせた。開始時の縦・横相対位置、実速度、
  方位、旋回半径は、56 traceから求めた線形校正式で入力3変数から決定する。地図上のspawnから
  開始イベントまでの走行はこの基準実験には含めない。
- 衝突は中心間距離ではなく、AWSIM traceの車体寸法（ego `4.886 x 2.186 m`、NPC
  `4.64 x 1.94 m`）を使った向き付き矩形の交差で判定した。`dx0` は車体間の縦方向
  clearanceとして扱い、actor原点へ車体中心offsetを適用して校正した中心間距離へ変換する。
- 全成果物は `artifacts/dynamics_uturn_baseline_20261005_fixed/` に保存した。

## 結果

ODEは3代表ケースで衝突ラベルとJAMA Zoneが全刻み幅で不変だった。TTCはAWSIM CVMと同じ
5秒horizon・0.1秒刻みのOBB等速予測へ統一したため、危険ケースは全刻みで `0.0 s` となった。

`ego_speed=36 km/h`、`npc_speed=18 km/h` のODE `dx0` 掃引では、衝突から非衝突への遷移は
`12.0--12.5 m` にある。零ノイズSDEも同じ `12.0--12.5 m` であり、代表ケースを含む
全比較で `min_ttc` の絶対差は `0.0 s` だった。

旧結果の約0.5 mのずれは物理ノイズではなく、零ノイズでもEuler--Maruyamaを通していたために
生じた固定刻みとイベント切替の数値偏りだった。拡散係数がすべて0の場合をODEへ合流させ、
「零ノイズSDE = ODE」というモデル上の極限を実装でも保証した。

境界候補 `dx0=12.25 m` では零ノイズ時に衝突となった。ego制動ノイズ0.25で衝突率0.89、
0.5で0.74となった。NPC加速度・方位ノイズの試行はこの点ではほぼ全件衝突だった。ただし、
ノイズ強度は未校正なので、これは感度観測であり現実の危険確率
ではない。

## Autoware制動校正

既存AWSIM Uターンtraceを無作為順に200件検査し、制動応答を抽出できた80件を56件の校正用と
24件のhold-out検証用に分離した。NPC方位が2度以上変化した時点をUターン開始とし、ego速度を
0.2秒窓で平滑化して制動開始、立上り時間、最大減速度を抽出した。

- 反応遅れ: `0.601 s`（経験的10--90%範囲 `0.467--0.733 s`）
- jerk立上り時間: `0.166 s`（`0.100--0.3085 s`）
- 最大減速度: `3.908428 m/s^2`（`3.712597--3.966209 m/s^2`）
- hold-out中央値絶対誤差: 遅れ `0.0325 s`、立上り `0.0575 s`、最大減速度
  `0.044409 m/s^2`

比較モードはこの `autoware171_uturn_calibrated` profileを使う。単独ODE/SDE実験は、JAMAの
理論条件を検証できるよう従来どおり `jama_ai_aeb` を既定とする。校正値はAutowareの応答を
3パラメータの制動曲線へ近似したもので、軌跡全体やTTCの一致を保証するものではない。

## 次の受入ゲート

零ノイズ同値、ケース別開始幾何、CVM TTC共通化を完了した。事前確保した別の100件による
最終比較では衝突感度100%、連続TTC MAE 0.141秒だった。一方、非衝突50件中28件を危険候補
として過検出した。次はこのfalse positiveを下げる軌跡追従モデルを開発用データで調整し、
さらに別の未使用集合で確認する。その後、実測残差からSDEの拡散強度を推定する。

hold-out 24件による最初の外部比較結果は
`docs/dynamics_awsim_holdout_validation_20261005.md` に記録した。
100件の最終比較は `docs/dynamics_awsim_final_validation_20261006.md` に記録した。
