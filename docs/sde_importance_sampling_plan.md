## 計画の概要

汎用的な検証ツールの重点サンプリング機能を SDE へ広げます。利用者は P と判定条件を与え、用意された Q の方式を選んで、調整を繰り返します。
ツールは、生成、尤度比、記録、比較を共通化します。最適な Q の自動探索は、初期実装の必須条件にしません。

実装の順番は次のとおりです。

1. 評価と保存の整合性を先に確保する。
2. OU モデルを使う最小構成を最初から最後まで通す。
3. その後で、状態依存 Gaussian、Student-t、経路単位の混合 Q へ広げる。

計算器だけを変えても、現在の U ターン専用の設定・出力・判定は汎用化されません。そのため、この接続部分も対象にします。

| 工程 | 完成させるもの | 次へ進む条件 |
|---|---|---|
| S0 | 基準コードと仕様の固定 | 監査結果と対象確率を記録 |
| S1 | 重みと評価の整合性 | ゼロ重み・失敗・再開を検証 |
| S2 | モデル追加口と OU の一貫実行 | CLI から推定と再開まで成功 |
| S3 | 条件付き Gaussian と状態依存規則 | 生成と密度の一致を検証 |
| S4 | Student-t と経路単位の混合 | 混合分母と上限を検証 |
| S5 | 比較実験と拡張性の評価 | 被覆率と独立した最終評価を保存 |

最初の実装単位は、S1 と S2（OU の一貫実行）です。PRISM と AWSIM の重点化方式は広げません。共有部を変えた場合は、回帰確認だけを行います。

### 既存の防御的混合は活用できる

E02 では、経路の開始時に P か R かを一度だけ選び、実現した同じ経路を P と R の両方で評価しています。最後に経路密度の混合を計算します。

Q=P の既存経路では、余分な乱数を消費しません。

### 失敗記録を除く既存動作との関係

既存の抽出処理には、利用できる記録だけを見る診断用途があります。互換動作を無条件に壊すことはせず、最終評価用の厳格な監査を追加します。

MC と IS、または異なる Q 同士を比較するには、P・数値写像・事象が一致している必要があります。
Q は比較群の間では違ってよいものの、固定 Q で評価する一群の中に複数の提案設定が混ざってはいけません。単なる ID 文字列の一致では、この条件を代わりに確かめられません。

## 3. 対象確率と理論上の境界

基本の対象は、Brown 運動で駆動する有限次元の Itô 型 SDE です。線形性、状態の次元、ノイズの次元は固定しません。
時刻と状態に依存する f と G、およびモデル側で定義したモード切替とリセットを許します。
ただし、個々のモデルの解の存在や数値安定性を、ツールが自動で証明することは想定しません。

### 最初に保証対象を数値モデルへ固定する

初期実装で推定するのは、次をすべて固定した数値モデルの事象確率です。連続時間の真の到達確率とは区別します。Euler–Maruyama の位置付けは文献 R1 に従います。

- 刻み幅 h、終端時刻 T
- 射影、遷移規則、格子上での事象判定

数値写像は次のとおりです。

```text
X_{k+1} = X_k + f(X_k, t_k) h + G(X_k, t_k) √h ξ_k
```

- 式の後に適用する射影とモード遷移も、P と Q で共通にします。
- 最後のステップが h 未満になる場合は、実際の刻み幅を使います。
- 初期状態と各 innovation を明示的な乱数源として記録し、その生成密度の比で補正します。G の逆行列は要求しません。

単一成分の Q の場合、経路の重みは次のとおりです。

```text
w = p₀(z) / q₀(z) × Π_k p_k(ξ_k | c_k) / q_k(ξ_k | c_k)
```

- c_k は、生成する直前の時刻、状態、モードなどの情報です。
- 経路単位の混合では、成分ごとに密度の積を作ってから混ぜます（§5）。
- P の innovation は通常 N(0, I) とします。既存設定の非ゼロ平均は互換経路で扱います。
- 入力を変えない場合は、初期入力の比を 1 にします。
- 射影によって写像が非可逆になる場合も、元の乱数源に対する補正を使います。

### 拡張によって混同しない条件

次の 3 つは別々に判定します。

- P が質量を持つ範囲を、Q でも生成できること
- 推定量の分散が有限であること
- 信頼区間の前提が満たされること

共分散の変更や Student-t の使用を許すのは、固定した数値モデルの乱数源に対する IS としてです。
連続時間で拡散係数を変えても同じ Girsanov 補正でよい、とは主張しません（R2 も参照）。

OU 型の相関ノイズは、状態を増やして表現します。次のものは初期実装に含めません。

- ジャンプ、真の遅延、fractional Brown 運動、無限次元モデル
- 切替の発生確率そのものの重点化

## 4. モデルと分布の追加口を分ける

モデルを追加する作業と、Q を追加する作業を独立させます。ターゲット全体の登録機構は既存のものを使い、Dynamics の内部にモデル登録を追加します。

| 追加口 | 利用者が用意する情報 | ツールが引き受ける処理 |
|---|---|---|
| モデル | 状態名、初期条件、f、G、ノイズ名、遷移・射影 | 設定の検証と、共通 SDE 実行器への接続 |
| 入力法則 | 固定値、または密度を計算できる入力の P と Q | 生成、入力の対数密度、入力の重み |
| 判定器 | 軌道に対する事象と、必要な指標 | 全標本への判定、記録、比較 |
| 提案分布 | `sample` と `log_density`、パラメータ、成立条件 | 生成時と同じ条件での密度評価、経路の重み |
| 調整 | 候補の選択、数値設定、調整結果の採否 | 試行の保存と可視化、最終設定の固定 |

### モデルアダプターの責務

アダプターは次の処理をまとめて受け持ちます。

- モデル定義の解決と検証
- 入力から `HybridSystem` を作る処理
- 軌道の判定
- 状態名に従った出力

U ターンの校正・車両幾何・衝突判定は UTurn アダプターに残します。OU を追加するときに、共通のバックエンドを書き換えない構造にします。

新しい汎用の軌道形式は、状態名、状態配列、時刻、モード、判定結果を持ちます。
既存の U ターン raw JSON（schema 1）は引き続き読み、新形式は schema 2 として識別する案とします。
CLI の既定の評価指標もモデルから解決し、OU に衝突指標を強制しません。

### 条件付き提案の契約

- 生成する直前に、読み取り専用の context を渡します。中身は、時刻、実際の刻み幅、現在の状態、モード、モードに入った時刻、順序付きのノイズ名、初期入力です。
- `sample(context, rng)` と `log_density(value, context)` は、同じ正規化済みの分布を表します。
- 履歴を使う拡張でも未来の乱数は参照せず、評価する成分の間で同じ実現履歴を使います。
- 規則は最終評価の開始前に固定し、経路の間で学習しません。内部状態を持つ拡張は、経路ごとに初期化します。
- 勾配、自動微分、fit 関数は必須にしません。

### 初期入力の参照測度

- 固定値用の `PointMass`、既存の一様分布・ヒストグラム、連続多変量分布を明示的に区別します。
- 固定の P を連続の Q で置き換えるような、互換でない参照測度は拒否します。Dirac 分布を通常の密度値で代用しません。
- 入力が確率的なら、入力の比とノイズ経路の比を組み合わせます。

## 5. 初期実装で用意する Q

既定では、少数のパラメータで設定できる分布族を用意します。状態依存の規則や混合成分は、必要な対象にだけ増やします。
汎用性を「任意の最適関数を自動で導くこと」とは定義しません。

| 方式 | 組込み機能 | 検証で注意する点 |
|---|---|---|
| Gaussian | 多変量の平均と、対角・完全共分散 | Cholesky で正定値を検査する。断りのない jitter や切り詰めで分布を変えない |
| 状態依存規則 | 定数、時刻・モードの区分、状態のしきい値、アフィン関数 | 現在の状態で平均を計算する。共分散の基本形は固定またはモード別 |
| Student-t | 多変量の位置、尺度行列、自由度 ν | 尺度と共分散を混同しない。ν > 0、比較の初期値は ν = 5 |
| 有限混合 | 経路ごとに成分を一度だけ選ぶ | 選んだ成分だけでなく、全成分の経路密度を分母に使う |
| 防御的混合 | 基準の P を重み β で混ぜる（任意の機能） | ノイズ部分の重みの上限は 1/β。入力の比の上限とは別 |

### 平均の単位と既存設定の変換

新しい設定では、innovation の平均と共分散を直接指定する方式を基本にします。
既存の `gaussian_drift` は SDE のドリフトの単位なので、innovation の平均へは √h 倍して変換します（既存コード E02 と同じ）。
設定には単位と解釈を記録し、同じ数値が別の意味で読まれないようにします。
状態や履歴に依存する任意の共分散は拡張関数で追加できますが、毎回の正定値性の確認と密度計算が必要です。

### 混合は経路密度で計算する

```text
q_path = β p_path + (1 − β) Σ_j α_j r_{j,path}
```

- 各成分の条件付き log density を、生成された同じ状態と innovation で、全時刻にわたって加算します。
- 最後に、混合係数を含めて log-sum-exp を取ります。係数 α の非負性と、合計が 1 であることを検査します。
- ステップごとの混合密度の積は別の Q になるので、同じ方式としては扱いません。
- 防御的混合では 0 < β ≤ 1 を検査し、β = 1 は P のみとします。
- 防御的混合は必須ではなく、上限のある評価が必要な場合に選びます（R2 参照）。

例として β = 0.2 なら、ノイズ経路の重みの上限は 5 です。初期入力の重みの上限が B₀ なら、全体の上限は 5B₀ になります。
入力の重みが無界なら、ノイズだけを防御的にしても全体の有界性は保証されません。

## 6. 重みと最終評価の整合性

### 6.1 厳密なゼロと計算失敗を区別する

Q が P の支持の外で正当な値を生成した場合の重み 0 は、捨てるべき異常値ではありません。予定の N のうちの 1 標本として保持します。
一方、全域に支持を持つ Gaussian などで密度の計算が数値的に破綻した場合は、厳密なゼロに置き換えません。

共有メタデータに version 2 を追加し、`weight_kind` を `positive` または `zero` で表す案とします。

- `positive`: 従来どおり、有限の `log_p`、`log_q`、`log_weight` を持つ。
- `zero`: `log_p` と `log_weight` を JSON の null とし、`log_q` は有限値とする。
- NaN や Infinity は JSON へ書きません。旧形式は `positive` として読めるようにします。

E07 の契約から、保存・読み込み・評価まで一貫して更新します。

### 6.2 対数領域で寄与を集計する

推定量は次の式です。

```text
π̂_IS = (1/N) Σ_i w_i Y_i
```

- w·Y の計算では、Y = 0 を先に処理し、正の寄与は `log_weight` と log Y から計算します。
- log-sum-exp と、尺度を調整したモーメント計算で、過大な指数変換を避けます。
- 結果が表現範囲を超える場合は数値状態を明示します。標本の除外や、重みの上限への切り詰めで補いません。
- 通常 IS の生の点推定は 1 を超えることがあるので、その値を保存します。確率の信頼区間を [0, 1] と交差させる表示とは別に扱います。
- 自己正規化 IS へ暗黙に切り替えません。

### 6.3 区間は役割で分ける

区間は次の 3 種類を別々に記録し、役割を混同しません。

| 区間 | 前提 | 役割 | Q の順位付けに使うか |
|---|---|---|---|
| 正規近似の診断区間 | 中心極限定理による近似。保証はない | Q 候補の効率比較（区間幅、ESS、推定値のばらつき） | 使う |
| 有界寄与の Hoeffding 区間 | 寄与 w·Y が既知の上限 B 以下 | **保証の確認だけ**に使う | 使わない |
| 有界寄与の経験的 Bernstein 区間 | 同上 | **保証の確認だけ**に使う。Hoeffding より分散に適応する | 使わない |

有界寄与の区間を Q の比較に使わない理由は二つあります。

- 上限 B が大きい Q は、実際の分散が小さくても区間が広くなり、不当に不利に見えます。
- 稀な事象では、現実的な N で区間幅が対象確率より桁違いに大きくなり、情報を持ちません。

下の表は、モデル A（§12）、信頼度 95% での見積もりです。B は寄与の上限です（β = 0.5 なら 2、β = 0.2 なら 5。初期入力は固定）。

| N | B | Hoeffding 区間の幅 | 経験的 Bernstein 区間の幅の下限（分散 0 でも残る項） |
|---|---|---|---|
| 1,000 | 2 | 0.172 | 0.049 |
| 1,000 | 5 | 0.430 | 0.123 |
| 10,000 | 2 | 0.054 | 0.0049 |
| 10,000 | 5 | 0.136 | 0.0123 |

区間の幅を対象確率 p 以下にするのに必要な N:

| 事象 | p | B | Hoeffding | 経験的 Bernstein（下限） |
|---|---|---|---|---|
| 3σ 片側 | 1.35×10⁻³ | 2 | 1.6×10⁷ | 3.6×10⁴ |
| 3σ 片側 | 1.35×10⁻³ | 5 | 1.0×10⁸ | 9.1×10⁴ |
| 4σ 片側 | 3.17×10⁻⁵ | 2 | 2.9×10¹⁰ | 1.6×10⁶ |
| 4σ 片側 | 3.17×10⁻⁵ | 5 | 1.8×10¹¹ | 3.9×10⁶ |

経験的 Bernstein 区間は、Hoeffding 区間より必要な N が 2〜4 桁少なくなります。
それでも、本計画の最終評価（N = 1,000 と 10,000）では、3σ・4σ の事象を区間幅 p 以下で保証することはできません。
保証付きの区間は「真値を含むか（被覆率）」の確認に使い、「区間が十分に狭いか」は求めません。

### 6.4 経験的 Bernstein 区間を追加する

既存の EBStop（`evaluation/ebstop.py`）と同じ不等式を、固定 N で 1 回だけ評価する形で使います（Audibert, Munos, Szepesvári 2009。R4）。
寄与 Z_i = w_i Y_i ∈ [0, B]、標本数 N、誤り率 δ のとき、確率 1 − δ 以上で次が成り立ちます。

```text
|Z̄ − E[Z]| ≤ σ̂ √(2 ln(3/δ) / N) + 3 B ln(3/δ) / N
```

σ̂ は標本の標準偏差（分母 N）です。

- EBStop との違い: EBStop は相対誤差で止める逐次の規則で、誤り率を時刻ごとに分けています。本計画では N を事前に固定し、1 回だけ評価するので、δ をそのまま使えます。
- 実装の場所: `evaluation/weighted_sequential.py` の `calculate_bounded_hoeffding_interval` の隣に、固定 N 版を追加します。
  半径の計算式は `evaluation/ebstop.py` と共通の関数にまとめ、同じ式を二重に持たないようにします。
- B の根拠: 観測した最大値を B の根拠にしません。防御的混合の β と、入力の比の上限 B₀ から事前に決めた値だけを使います。
- N < 2 では区間を出さず、情報不足とします。
- 逐次版（confidence sequence など）は、初期実装には含めません。

### 6.5 最終評価の完了条件

| 記録する件数 | 判定 |
|---|---|
| 予定・試行・実行成功・判定済・重み確定・ゼロ・未解決 | 一意な標本 ID と照合し、二重計上を検出する |
| 実行失敗・未判定・重み不明・数値破綻のどれかがある | 最終評価は未完了。再実行は同じ標本の再試行として残す |
| 事象を観測しない、または標本が 1 件 | 正規近似による確実な区間を表示しない。情報不足と付記する |
| 既知の上限 B を満たす全標本が揃う | Hoeffding 区間と経験的 Bernstein 区間を計算できる（保証の確認用） |

基本の評価では、独立な最終の N を事前に固定します。有界重みを使わない方式では診断用の推定も許しますが、区間の前提は別に確認します。
既存の逐次停止法を、初期実装の必須機能には追加しません。

## 7. 乱数と実験の再開を管理する

同じ P・Q で評価したことと、各標本を再現できることを、保存件数や表示名に頼らずに記録します。
現在の単一の seed と件数に基づく再開を、新形式の実験 manifest で補います（E12–E17 参照）。

| manifest の項目 | 内容 |
|---|---|
| 対象の指紋 | 解決済みの P、モデル実装の版、初期法則、f・G の設定、状態とノイズの順序・単位 |
| 数値写像と事象 | h、T、実際の solver、ノイズが無いときの ODE 委譲、射影、guard、reset、判定器の定義と版 |
| 提案の指紋 | 正規化した Q の設定、条件付き規則、関数の実装の版、混合成分と係数、上限 B の根拠 |
| 乱数と評価計画 | root、乱数方針の版、phase、反復 ID、標本 ID、stream、予定の N、固定した比較条件 |
| 実行と保存 | コードの版、依存の版、実行条件、成果物の方針、試行履歴、完了状態、必要な checksum |

### 独立な系列と再現性を両立する

- root が指定されていない場合も、実験の開始前に一度だけ生成して保存します。
- pilot、final、reference を分けます。反復・標本・用途ごとに、`SeedSequence` の entropy と spawn key を記録します。
- 入力、混合成分の選択、innovation で、乱数系列を分けます。
- 大規模な実験の識別を、32 bit 整数だけに圧縮しません。既存の明示 seed の動作は旧方針として残します。

MC と IS の関係は次のように扱います。

- 新形式の既定では、MC と IS を独立にします。
- 同じ乱数を使う比較を選ぶ場合は paired 設計として記録し、差の分散にもその対応を反映します。
- 旧形式は同じケースの seed を使うので、独立な比較と誤認しないようにします。
- 乱数系列を分けただけで独立性を実証したとはせず、生成の方針を明示します。

### 再開は一意な標本 ID で行う

- 最初の標本を作る前に manifest を保存します。再開時は、対象・Q・乱数方針・予定の N などを照合します。
- 既存の件数に 1 を足すのではなく、完了した標本 ID を調べます。
- 失敗は、同じ入力・同じ乱数での再試行として attempt ID を付けます。未解決の標本を新しい乱数で置き換えて「成功するまで生成」しません。
- P と Q の固定の指紋は分布の定義から作り、生成されたランダムな初期値そのものの hash とは分けます。
- 実行時の params の上書き後の有効な設定を使い、resume で設定の食い違いを検出します。
- 既存の manifest なしの結果は診断用には読めますが、新形式の厳格な再開へ自動的には昇格させません。

## 10. 設定と利用手順の設計案

外側の `SamplingPlan` は維持したまま、Dynamics 固有の定義の中で新形式を識別します。
次の例は項目を合意するためのもので、現行の CLI でそのまま実行できる設定ではありません。入力の P/Q とノイズの Q は、別の項目として持ちます。

```yaml
target_definition:
  dynamics_schema_version: 2
  model_id: ou_scalar
  initial_law: {kind: point_mass, value: [0.0]}
  solver: {kind: sde, dt_sec: 0.01, horizon_sec: 1.0}
  event: {kind: terminal_exceedance, threshold: 2.0}
proposal_definition:
  dynamics_schema_version: 2
  input: {kind: same_as_target}
  noise:
    kind: gaussian
    mean_rule: {kind: affine_state, offset: [0.5], matrix: [[0.1]]}
    covariance: [[1.0]]
experiment:
  rng_policy_version: 2
  root_seed: 20261022
  phase: final
  planned_samples: 1000
  evaluation_policy: complete_fixed_n
```

`experiment` は実行設定と manifest に保存し、外側の `SamplingPlan` には項目を増やさない設計とします。
上の `threshold: 2.0` と Q のパラメータは書式の例であり、推奨値や実験の最終条件ではありません。

### 利用者の作業

1. P のモデルと初期法則、事象、h と T を定義する。
2. Q の分布族と少数の規則を選び、pilot を繰り返して候補を比べる。
3. 最終の Q と N を固定した後、pilot とは別の系列で final を実行する。

各段階で、ツールが設定の指紋と条件を保存します。

### 自由度を増やす判断

- 最初は、定数や簡単な区分の規則を使います。
- 事象が複数の領域に分かれる場合や、一つの平均では寄与が偏る場合に、状態の特徴や混合成分を増やします。
- 自由度を増やしたことによる改善だけでなく、設定項目の数、調整の試行数、設定にかかる時間、密度計算の費用も比べます。
- 高度な関数を必須にしません。

CE（交差エントロピー法）や分散最小化などの自動調整を後から追加しても、固定された Q を実行する部分は同じ API を使えます。
初期版では、自動調整の収束や最適性を成果の条件にしません。

## 11. 受入テストと実行環境

分布ごとの数値の確認に加えて、CLI から保存・再開・比較までを通します。
推定値がたまたま近いことだけを合否の条件にせず、小規模な密度計算や一意な記録 ID で確認できる条件を優先します。

| 検証対象 | 最低限の受入条件 |
|---|---|
| 基準と互換性 | Q = P で重み 1。旧設定・明示 seed の軌道と指標が一致。ノイズが無いときの ODE 委譲を保持 |
| Gaussian と t | 1 次元・多変量の log density が参照式と一致。不正な共分散・次元・ν を拒否 |

| 経路単位の混合 | 成分の選択は 1 回。全成分の分母と一致。β = 1、複数成分、上限を検証 |
| 初期入力と G | 入力の比とノイズの比を合成。2 状態・1 ノイズの矩形・階数不足の G でも実行可能 |
| モード切替 | チャネルの数と順序が変わる例で、生成と密度評価が一致 |
| 重みの特殊値 | 厳密な 0 を N に保持。大きな log weight、0×過大な重み、数値失敗を区別 |
| 推定と区間 | 生の IS 平均 > 1 を保持。事象未観測の [0, 0] を確実な区間として扱わない |

| 失敗と再開 | 未解決があれば未完了。同じ標本の再試行。重複や異なる P/Q での再開を拒否 |

| 共有部の回帰 | PRISM と AWSIM のメタデータ・保存・評価の既存テストを維持 |

## 12. 評価対象となる P と事象を固定する

| P の例 | 確認する性質 | 基準値 |
|---|---|---|
| A スカラー OU | Q = P、平均・分散の変更、片側と両側の稀な事象 | 離散化後の厳密な Gaussian 確率 |
| B 状態を拡大した OU | 2 状態・1 ノイズ、相関ノイズ、階数不足の G | 離散共分散の漸化式による終端確率（厳密） |
| C 非線形の試験モデル | 非線形の f と状態依存の G、格子上でのしきい値到達 | 独立した大規模 MC とその不確実性 |
| D 既存の U ターン | 既存の切替・射影・衝突判定を伴う接続 | 独立した MC の参照値。真値とは呼ばない |

### モデル A

dX = −X dt + dW、初期値 0、T = 1、h = 0.01 とします。a = 1 − h、K = 100 として、離散モデルの終端分散を次の式で計算します。

```text
v_K = h (1 − a^{2K}) / (1 − a²)  = 0.43519
```

（連続時間 OU の分散 (1 − e⁻²)/2 = 0.43233 とは異なります。連続時間の分散を数値モデルの真値の代わりにしません。）

- しきい値は、標準偏差の 3 倍と 4 倍を使います。片側の確率はそれぞれ 1.35×10⁻³ と 3.17×10⁻⁵、両側はその 2 倍です。
- 片側・両側で、平均変更と混合の差を調べます。

### モデル B

dC = −2C dt + dW、dX = (−X + C) dt、初期値 0 とします。
状態 z = (C, X) の Euler–Maruyama は z_{k+1} = A z_k + √h b ξ_k（A = [[1 − 2h, 0], [h, 1 − h]]、b = (1, 0)ᵀ）です。
共分散 Σ_{k+1} = A Σ_k Aᵀ + h b bᵀ を K ステップ計算すると、終端の X は平均 0、分散 Σ_K[1,1] の Gaussian なので、終端で超える確率を厳密に求められます。

### モデル C

大域的に Lipschitz なドリフトと、有界で滑らかな状態依存の拡散係数を使います。しきい値は独立した pilot で決めて固定します。
初期状態を 2 次元の 0、T = 1、h = 0.01 とし、係数は次の式で実装します。
共分散の相関と状態依存性を含み、各格子時刻でいずれかの座標が固定のしきい値を超えたかを判定します。

```text
f  = [-x1 + 0.5*tanh(x2), -x2 + 0.5*tanh(x1)]
a1 = 1 + 0.25*tanh(x1)
a2 = 1 + 0.25*tanh(x2)
G  = 0.5 * [[a1, 0], [0.5*a2, sqrt(0.75)*a2]]
```

### モデル D

既存の UTurn モデルの P、衝突判定、h、T を固定します。実験用のモデルを追加しても、既存の AWSIM シミュレーターへの機能追加は必要ありません。

各モデルの式、係数、事象、数値範囲は、評価設定ファイルとモデルのテストで固定します。

## 13. 被覆率の検証を既存の枠組みに載せる

初版では、最終評価を 30 反復としていました。30 反復では、被覆率 95% の推定誤差が ±8% 程度になり、「約束を守っているか」を判断できません。
モデル A と B は真値を式で求められ、計算も軽いので、2,000 反復ずつ回します（Clopper-Pearson 区間で ±1% 程度）。

### 既存の検証ツールへの載せ方

`tools/validation/coverage_experiment.py`（2026-10-18 作成、結果は `docs/validation/coverage.md`）は、次の方針で作られています。本計画でも同じ方針を守ります。

- 実験で実際に使う評価コードをそのまま動かし、保存先だけを一時ディレクトリまたはメモリに置き換える。
- 1 条件 = `Scenario`、1 回 = 1 seed。結果を `judge` で正誤判定し、`summarize` が被覆率と Clopper-Pearson 区間を出す。

追加するもの:

1. engine `importance_fixed`
   - `orchestration/fixed_importance_sampling.py` の固定 N の比較（S1 で厳格化したもの）を、そのまま呼ぶ。
   - 1 回の実行で、MC と IS の両方の推定値と、3 種類の区間（正規近似・Hoeffding・経験的 Bernstein）を返す。
2. 真値の与え方
   - 現在の `judge` は bernoulli の真値だけを扱う。`Scenario` に真値を計算する関数（モデル A・B の厳密確率）を持たせる形に一般化する。
3. 判定
   - 区間ごとに「真値を含むか」を判定し、区間の種類別に被覆率を出す。
   - 同じ実行から、バイアス、分散、RMSE、平均の区間幅、事象を観測しなかった割合、情報不足と判定された割合も集計する。

### 条件

| 項目 | 値 |
|---|---|
| モデル | A（3σ・4σ、片側・両側）、B（終端の X、しきい値は分散から決める） |
| 方式 | Q0（通常 MC）、Q1（既存の時刻・モード依存の Gaussian 平均）、Q2〜Q5（S3・S4 の完成後に追加） |
| 防御的混合 | 代表的な条件で、β = 0.2 の有無を比較する |
| N | 1,000 と 10,000 |
| 反復 | 各条件 2,000 回 |
| 信頼度 | 名目 95% |

各区間について確かめることは次のとおりです。

- Hoeffding・経験的 Bernstein 区間（保証の確認用）: 被覆率の Clopper-Pearson 区間の上端が 95% を下回らないこと。下回れば実装か前提の誤りとして扱う。
- 正規近似の診断区間: 被覆率を測って記録する。稀な事象・小さい N では 95% を下回ることが予想され、その程度を `coverage.md` に残す。

### 計算費用

条件数 × 2,000 反復 × N × 2（MC と IS）の経路を計算します。N = 10,000 では、1 条件あたり 4×10⁷ 経路になります。

- S2 で、1 経路あたりの時間（モデル計算、記録の保存、集計を含む）を測ります。
- 全条件の所要時間を見積もってから、N = 10,000 で回す条件を決めます。
- 保存の I/O が支配的なら、要約保存（§13 末尾）を先に入れます。

### 評価値と保存費用

- A・B は、厳密な数値モデルの確率に対して、バイアス、分散、RMSE、区間の被覆率を評価します。
- C・D は真値が無いので、被覆率は測りません。参照推定の不確実性を併記して、推定値を比べます。
- ESS は診断値として扱います。
- 生成・密度・モデル計算・保存・集計を含む時間と、設定項目・試行数・人の作業時間を、別々に記録します。
- 高次元での重みの不安定性と費用は、R3 を踏まえて解釈します。

現状の全 CSV 保存と再読込みの費用を測り、必要なら、全標本の判定をメモリ内で完了する要約保存を追加します。
推定用の記録を選り分けず、旧 CSV での判定と一致することをテストします。
共通基盤を固定した後に Laplace 提案を追加し、モデル B の追加と合わせて変更範囲を測ります。開発者一人の作業記録から、一般の利用者にとっての使いやすさを断定しません。

### 比較群と予算

| 群 | 内容 |
|---|---|
| Q0 | 通常 MC |
| Q1 | 既存の時刻・モード依存の Gaussian 平均 |
| Q2 | Q1 と同じ依存性で、共分散も変更 |
| Q3 | 状態依存の平均と単位共分散 |
| Q4 | Q3 と同じ規則の Student-t（ν = 5 から始める。共分散を揃える場合は尺度を調整する） |
| Q5 | 経路単位の 2 成分混合 |

調整（pilot）の予算は、最大 10 試行 × 1,000 経路とします。β = 0.2 を比較の出発点にします。
これらは、十分性や最適性について文献上の保証があるわけではありません。pilot の費用と事象の頻度を見て、最終評価の前に予算を確定します。
被覆率の検証（2,000 反復）は、pilot とは別の乱数系列で行います。
